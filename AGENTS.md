# AGENTS.md — кодекс разработчика движка Bot Fork

Этот файл — твой промт, если ты открыт как исполнитель пакета в `bot-fork/`.
Движок — **отдельный репозиторий**, editable-установлен в продукт
(`~/Предприниматель/teamwinning-app/.venv`), поэтому правки видны продукту
сразу; продукт пинится на тег (`pyproject.toml`, сейчас `@v1.12.10`).

## Что читать до первой правки

1. `README.md` — назначение, установка, **«Версионирование»** (главное правило).
2. `docs/History.md` — что уже выпущено (последняя версия — сверху/в конце).
3. `docs/TODO-ARCH.md` — очередь изменений серии (что и каким пакетом).
4. `docs/components/README.md` + документы нужного компонента:
   `ARCH.md` (норма) → `TODO-ARCH.md` (очередь) → `INTERNAL.md` (факт).
5. `docs/ARCH-CHANGE.md` — реестр меток правок норм (`RfI-NN`).

## Жёсткие правила

1. **Минор не задирать.** Небольшие прибавки API — **патчи внутри текущей
   минорной серии** (`1.12.1`, `1.12.2`, …). Новая минорная — только крупный
   связанный пакет или обратно несовместимая правка, и только по слову Мастера.
2. **Контракт через метку.** Меняешь `ARCH.md` (норму) — в том же коммите
   строка в `docs/ARCH-CHANGE.md` и метка `ARCH-CHANGE: RfI-NN` в коммите.
   Без метки правка нормы — красный страж продукта.
3. **Тесты.** `python -m pytest tests -q` — зелёные (сейчас 211 + 7 subtests);
   `agent_tools/test.sh bf` из продукта гоняет движок и печатает клон/HEAD.
   Тест нового поведения обязателен; skip — не зелёное.
4. **Пакет работы.** `agents/<пNN-тема>/README.md` начинается с YAML-шапки
   (`package: пN-…`, `role`, `zone_write`, `status`, `model`, `budget_m`) —
   шаблон и гейт в продукте (`agents/TEMPLATE/`, `agent_tools/packet_schema.py`).
   Коммиты — частичные, только свои пути, версия — третья цифра
   (перечитать `pyproject.toml` прямо перед коммитом).
5. **Документация в `docs/`, не в пакете.** `.md` в wheel не пакуются
   (package-data нет): модульные документы живут в `docs/components/`.
6. **Пуш — координатор**, не исполнитель. Ветку/историю не переписывать;
   расхождение версий при гонке — «большая + 1».
7. **Затруднение — начальству:** упёрся в чужой слой, спорный контракт или
   неоднозначность — блок «БЛОКЕР: …» в отчёте и короткое сообщение
   координатору; не обходить, не ставить skip.

## Связь с продуктом

- Нужной движку возможности не хватает продукту — это решает **продукт**:
  запись F-xx в рабочем листе Мастера (только чтение) и контракт в комнате
  (`Room_for_Improvement`, решения `D-NN`).
- Индекс задачи для учёта расходов — `пN`/`пN-N` (папка пакета), модель — по
  порядку назначения (`~/Предприниматель/МОДЕРНИЗАЦИЯ.md`).
