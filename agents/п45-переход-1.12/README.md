## 4. План перехода 1.11.6 → 1.12.0 (формулировки готовы к вставке)

### 4.1 Что считается «крупным связным пакетом»

Правило движка (`README.md:25-32`) разрешает минор за крупный связный пакет.
Пакет серии D2 = **модульная документация компонентов + карта F-xx + точная
базовая линия тестов**; закрытие самих F-xx идёт **патчами внутри 1.12.x**
(по одному на пакет — это и есть D2.3 «лёгкий рой»). Два варианта на выбор лида:

- **A (рекомендую).** `1.12.0` = **открытие серии**: модульная документация +
  правки README/истории + `docs/TODO-ARCH.md`. Ядро не тронуто → контракт v1.11.6
  сохранён полностью, продукт не обязан ничего менять, риск = 0. F-xx → 1.12.1, 1.12.2…
- **B.** `1.12.0` режется только вместе с первым закрытым F-xx (например F-35).
  Минор тогда «настоящий» по API, но D2.1 (модульность) обязана успеть до релиза,
  а рой стартует уже внутри новой серии — иначе нарушается порядок Мастера.
