# п49-4 — версия из метаданных, конец ручной синхронизации (1.12.9)

Решение `D-19`, RFC-06; замечание п49-2 №4 и урок гонки версий.

## Проблема

`bot_fork/__init__.py:__version__` синхронизируется вручную и снова разъехался:
1.12.5 при `pyproject` 1.12.8. Каждый патч даёт лаг и путаницу в логах/репортах.

## Задача

1. `bot_fork/__init__.py`: `__version__` — из метаданных установленного пакета
   (`importlib.metadata.version("bot-fork")`), с fallback на константу, если
   пакет не установлен (запуск из клона). Никаких ручных цифр в коде на
   нормальном пути.
2. Тесты: `__version__` не пустой; совпадает с метаданными, когда пакет
   установлен; fallback не падает; `app/INTERNAL.md` — факт «версия из
   метаданных».
3. `pyproject.toml` → 1.12.9; `docs/History.md` — строка.
4. Устаревшие счётчики, перечисленные п49-2 (замечание 3): `docs/components/README.md`
   «база 158 passed», `docs/components/docs/ARCH.md` инвариант 2 «сейчас 158»,
   `README.md` «Текущая версия»/«158 тестов» — привести к факту (185+7).
5. `docs/TODO-ARCH.md`: строку «читать __version__ из метаданных» → внедрено.

Правила: только `bot-fork/`; `python -m pytest tests -q` зелёные; коммит
`fix(версия): __version__ из метаданных (1.12.9)`; версия третьей цифрой,
пуш не делать; в отчёте — модель (Qwen), шаги, токены (сырые/оценка), тесты, хеш.
