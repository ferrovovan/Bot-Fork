## Ключевые решения (и почему так)

| Решение | Зачем | Где |
|---|---|---|
| Платформа проверяется в `__init__`, список (`telegram,vk`, `all`) отказывает `from_env` | конфигурационная ошибка видна на старте (одноплатформенный контракт, F-17 решён «двумя процессами») | `app.py:52-57,88-116` |
| Адаптер берётся по платформе; несовпадение `adapter.platform_name` — `ConfigError` | песочница с моком не запускает «чужую» платформу случайно | `app.py:76-86` |
| `on_system_event` оборачивается в `_dispatch_system_event` с try/except | хук, упавший на событии чата, не должен ронять диалог | `app.py:127-137` |
| Дедуп — `OrderedDict` LRU (ёмкость `max(1, dedupe_capacity)`, по умолчанию 1024) | платформы ретранслируют callback; кеш не растёт бесконечно (F-18) | `app.py:72-74,190-197` |
| `on_error` — пользователю нейтральный текст, в `HandlerResult.error` — `str(e)` с кодом `RUNTIME_ERROR` (F-20) | у продукта есть канал ошибок, у пользователя — нет трейсбека | `app.py:199-236` |
| `start_scene` идёт через `router.begin_scene` + доставка адаптером; `send_prompt=False` — тихий старт (F-22) | job/outbox начинает сцену без входящего события | `app.py:145-181` |
| Ленивые импорты `aiogram`/`vkbottle` внутри методов адаптеров | ядро импортируется без платформенных libs (NFR-03); факт 2026-11-04: на машине сборки их нет, сюита 158 зелёных | `adapters/telegram.py:342`, `adapters/vk.py:371` |
| `run()` — `asyncio.run` + тихий выход по Ctrl-C | CLI-вход без шума | `app.py:264-274` |
