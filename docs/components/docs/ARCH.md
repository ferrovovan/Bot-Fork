# docs/ARCH.md — Code Arch: какой должна быть документация движка

**Компонент:** `README.md`, `docs/History.md`, `docs/TODO-ARCH.md`, `docs/components/` ·
**Серия контракта:** `1.12.x` · **Правит:** совет архитекторов (метка `ARCH-CHANGE: RfI-NN`)

## Назначение

Держит: три поля документации — норму (`ARCH.md` компонентов), факт
(`INTERNAL.md`), очередь (местные `TODO-ARCH.md` + общая `docs/TODO-ARCH.md`);
README — вход, установка и правила версионирования; `History.md` — хронику
версий и закрытых F-xx.
Не держит: дублирования кода (факты — в INTERNAL с адресами), планирования вне
очередей, маркетинговых обещаний.

## Границы

| Можно | Нельзя |
|---|---|
| ссылаться на любой код как на источник фактов (с адресом `файл:строка` — только в INTERNAL) | факты внутри ARCH; «намерения» где-либо, кроме TODO-ARCH |

## Публичный контракт

- **README.md**: что за библиотека, установка, быстрый старт, правила
  версионирования, как гонять тесты.
- **docs/History.md**: по строке на версию: патч/minor, закрытые F-xx; хроника
  не переписывается задним числом.
- **docs/TODO-ARCH.md**: по строке на решение: `решение | что меняется | пакет |
  статус | дата`; статусы: `ждёт пакета/RFC` / `в работе` / `внедрено` /
  `отказ: причина`.
- **docs/components/<id>/**: три поля на каждый из 9 компонентов + индекс.

## Инварианты

1. Версия живёт в `pyproject.toml`; README и `History.md` называют ту же
   текущую; `bot_fork.__version__` согласован с релизным тегом. Проверяется
   ритуалом перехода, автоматической проверки нет — долг.
2. Число тестов в README равно фактически собираемому (база — в INTERNAL.md и
   индексе компонентов, в ARCH счётчиков нет) — проверяется прогоном на каждом
   переходе; автостражи нет.
3. Каждая закрытая дыра F-xx и каждый патч получают строку `History.md` в той же
   минорной серии — правило README «Версионирование».
4. В ARCH нет `файл:строка` и счётчиков; в INTERNAL нет норм; в TODO-ARCH нет
   фактов и норм — проверяется приёмкой пакета, скрипта нет — долг.
5. Хроника дополняется, но не переписывается: откат — новая строка, а не правка старой.

Где что лежит — [INTERNAL.md](INTERNAL.md).

## Запреты

- MINOR без слова хозяина; патч без строки истории — README §Версионирование.
- «Сделано» без строки кода/теста в хронике.
- Удалять строки очереди бесследно: отказ оформляется статусом `отказ: причина`.

## Чем проверяется

Документация сюитой не покрыта (тестов структуры в `tests/` нет — честно, это
долг). Проверка — ритуал перехода (п45) и приёмка пакетов; страж счётчиков и
версий заказан в [TODO-ARCH.md](TODO-ARCH.md).
