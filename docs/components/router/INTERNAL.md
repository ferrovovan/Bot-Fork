## Ключевые решения (и почему так)

| Решение | Зачем | Где |
|---|---|---|
| Реестр хранит два словаря (id→сцена, команда→id), уникальность проверяет `register` | коллизия команд видна на старте; `resolve_command` — O(1) | `router.py:30-59` |
| `list_scenes()` — публичный кортеж id по возрастанию (F-35, RfI-06-1): продукт уходит с чтения `_scenes` через getattr (`delete_account.py:30-34`) | контракт — обещание с тестом, а не внутренность; только id: `title` в модели нет, шаг — состояние хранилища (F-34) | `router.py:62-71` |
| `cancel_buttons` — кнопки продукта к обоим ответам `/cancel` (F-36, RfI-06-2, симметрия F-31) | возврат после отмены — UX-дыра; надписи и payload — политика продукта, движок текстов не изобретает (урок F-32) | `router.py:94,107,148,160` |
| Порядок `route`: system → cancel → старт → активная сессия → служебный | отмена обязана работать при перехвате; явный старт важнее текста активной сессии | `router.py:112-233` |
| Обе дорожки читаются разом (`system_session`, `user_session`) | выбор дорожки старта зависит от сцены, а не от удачи чтения | `router.py:169-170,184` |
| Результат FSM сохраняется в дорожке самой сессии: завершение системной открывает пользовательскую (F-06) | иначе подтверждение молча проглатывает опрос | `router.py:221-231` |
| `begin_scene` — общий путь команды, кнопки `scene:` и `app.start_scene` (F-22) | один запуск = одна семантика перезапуска | `router.py:235-332` |
| `restart_text`: `None` → «Диалог начат заново.», `""` → без префикса (F-27) | продукт жаловался на «диалог» в админском меню | `router.py:268-269` |
| Подсказка отмены строится из `commands_for`/`list_entry_commands` (F-32) | демо-команды не должны течь в продукт | `router.py:135-142` |
| Стартовая цепочка info продублирована из FSM (F-33) | цепочка обязана вести себя одинаково на старте и при переходе; не вынесено — долг | `router.py:290-332`, `fsm.py:299-342` |
| Активная сессия ищется system→user инлайном (`session = system_session or user_session`) | перехват важнее; отмена снимает тем же порядком | `router.py:184,207` |
