## Ключевые решения (и почему так)

| Решение | Зачем | Где |
|---|---|---|
| `StepDefinition`/`SceneDefinition` frozen; индекс `_step_map` дописан через `object.__setattr__` | сцена неизменяема после регистрации, индекс считается один раз | `scene.py:29-30,234` |
| Структурные ошибки — `ConfigError` на построении | битая сцена вскрывается на импорте/старте, а не в диалоге | `scene.py:45-67,218-262` |
| `Step.info` — отдельный `input_type` | сообщения «о проекте» не ждут ввода; исходный баг продуктовой приёмки | `scene.py:144-169` |
| Динамические prompt/клавиатура вызываются с сессией или без — по сигнатуре (`inspect`) | лямбды без аргументов и функции с данными живут по одному контракту (F-05/F-29) | `scene.py:69-82,103-112` |
| `resolve_buttons` прогоняет результат функции через `ButtonBuilder.keyboard` | функция возвращает клавиатуру под теми же лимитами, что статическая | `scene.py:87-101`, `builder.py:33-43` |
| Исключение из prompt/клавиатуры → `ConfigError`, а не падение роутера | сбой продукта — шум диалога, а не смерть процесса (F-29) | `scene.py:75-98` |
| `Scene(...)` нормализует команды (`strip`), `start_step_id` по умолчанию — первый шаг | короткий контракт разработчика; регистр команд доводит роутер | `scene.py:285-296` |
| Кнопки `scene:<id>` не требуют перехода | запуск перехватывает `DialogRouter` до FSM (F-23) | `scene.py:253-261` |
