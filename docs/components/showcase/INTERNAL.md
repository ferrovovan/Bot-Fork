## Ключевые решения (и почему так)

| Решение | Зачем | Где |
|---|---|---|
| Страница строится живым прогоном, а не рукописным «скриншотом» | Pages не умеет врать: изменилось ядро — изменился транскрипт | `build_pages.py:1-12`, workflow `pages.yml` |
| Стопор сборки — отсутствие «Чек» в выводе прогона | минимальная нитка «диалог дошёл до конца» (слабая — см. долги) | `build_pages.py:38-39` |
| Песочница зовёт Python на каждое сообщение (stdin→stdout JSON) | в TS нет второго FSM; состояние разговора — файл между процессами | `server.ts:31-45`, `handle_event.py:61-127` |
| Файл сессии `bot_fork_sess_<platform>_<user>.json`, 0600, id фильтруются `SAFE_ID_CHARS` | несколько посетителей на одной машине; путь не формируется из user input | `handle_event.py:27,40-47,104-108` |
| `demo_mars_pizza` — мок-адаптер + свой `run_scripted` и `--live` REPL | один и тот же текст транскрипта для Pages и терминала | `demo_mars_pizza.py:305-390` |
| Ошибки `handle_event.py` — traceback в stderr и ненулевой код возврата (успех и `--reset` печатают JSON) | `server.ts` на `execFile` честно показывает сбой бэкенда | `handle_event.py:41-42,59`, `server.ts:34` |

## Ограничения и долги

| `файл:строка` | Суть / как воспроизвести | Тяжесть | Решение | Метка |
|---|---|---|---|---|
| `web/` | во всём npm-мире ни одного теста (ни pytest, ни jest) — оболочка может тихо сгнить | средняя | хотя бы смоук `server.ts` | `RfI-candidate` |
| `build_pages.py:38-39` | стопор «транскрипт живой» — одна подстрока «Чек»; середину диалога, испорченную наполовину, ловит не всегда | низкая | проверять полноту по маркерам шагов | — |
| `handle_event.py:46-47` | общее `/tmp`: одинаковые `platform+user` у посетителей одного общего хоста сталкиваются состояниями (демо-сценарий осознанный) | низкая | префикс каталога через env | — |
| `ChatSimulator.tsx` | 563 строки компонента с логикой двух платформ — самая дорогая правка в репо без тестов | низкая | разбить/прикрыть смоуком | `RfI-candidate` |

## Как гонять

```bash
python -m examples.demo_mars_pizza            # витрина в терминале
python scripts/build_pages.py                 # _site/index.html
python3 -m pytest tests/test_demo_info.py -q  # часть сюиты (2 теста)
cd web && npm install && npm run dev          # песочница (узел обязателен)
```
