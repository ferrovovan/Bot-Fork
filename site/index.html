Bot Fork

Встраиваемая Python-библиотека диалоговых сцен для Telegram и ВКонтакте. Логика пишется один раз на чистом Python — бот меняется только конфигурацией окружения.

GitHub — README и установка Исходник витринного примера

Живой прогон, не картинка

Ни одного нарисованного ответа: этот лог сгенерирован настоящим ядром bot_fork на mock-адаптере прямо в GitHub Actions при каждой сборке страницы. 17 реплик примера «Марс-Пицца» — и на них видно 12 возможностей движка.

Повторить у себя: git clone https://github.com/ferrovovan/Bot-Fork && cd Bot-Fork, затем python -m examples.demo_mars_pizza — или сесть за игрока: --live. Токены не нужны.

Быстрый старт

# ядро + Telegram + VK
pip install "bot-fork[all] @ git+https://github.com/ferrovovan/Bot-Fork"

# сцена — чистый Python, без платформенных классов
from bot_fork import BotForkApp, Scene, Step, Button

order = Scene(
    id="order",
    entry_commands=("/заказ",),
    steps=(
        Step.choice("size", "Какой диаметр?",
                    buttons=(Button("20 см", "s20"), Button("30 см", "s30")),
                    next="toppings"),
        # … топпинги, адрес, свой чек через on_complete — в examples/demo_mars_pizza.py
    ),
)

app = BotForkApp.from_env()   # ENABLED_PLATFORMS=telegram или vk — и ничего больше
app.register_scene(order)
app.run()
